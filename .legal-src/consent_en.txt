Consent to Personal Data Processing
Last updated: 08/26/2026

This document describes the terms under which you provide consent to the processing of your personal data by the developer of the "Tapa" application — the individual Ivan Mironov (hereinafter — "Developer").

1. Data for Which Consent is Requested
By registering and using the Application through VK ID or Yandex ID, you consent to the processing of the following data:
• VK ID / Yandex ID account identifier, email address, and phone number (if provided by the respective provider);
• display name and profile avatar;
• habit and goal data (names, descriptions, settings), including data created within group goals;
• habit completion statistics;
• daily step count — only if you separately enabled Android Health Connect sync;
• device push token for sending reminders.
We do not collect app-usage analytics data and we do not create passwords — sign-in is done exclusively via VK ID / Yandex ID.

2. Purposes of Processing
The specified data is processed for the following purposes:
• providing Application functionality (syncing data across devices, group goals);
• sending push notifications with habit reminders;
• syncing physical activity metrics with Health Connect;
• identifying the user upon sign-in;
• communicating for technical support purposes.

3. Third Parties
Your data may be shared with the following services to ensure Application functionality:
• VK ID (VK LLC) and/or Yandex ID (Yandex LLC) — the provider you used to sign in to the Application; it supplies us with an access token and basic profile data;
• Google Firebase Cloud Messaging (FCM) — delivery of push notifications to your device.
The Application's database and files are stored on a server controlled by the Developer, not on third-party cloud infrastructure.

4. Duration of Consent
This consent is effective from the moment it is provided (signing in to the Application) until it is withdrawn or the account is deleted.

5. How to Withdraw Consent
You may withdraw this consent at any time. To do so:
• delete your account via the Application settings; or
• send a request to: apptapatap@gmail.com
After withdrawal of consent, data processing will cease and data will be deleted within 30 days.

6. Consequences of Withholding Consent
Providing the data required to sign in via VK ID / Yandex ID is a prerequisite for using the Application — without it, an account cannot be created. Consent for push notifications and Health Connect sync is optional and does not affect your ability to use the rest of the Application's features.

7. Your Rights
Under applicable law, you have the right to:
• request access to your personal data;
• request correction of inaccurate data;
• request deletion of your data ("right to be forgotten");
• restrict the processing of your data;
• receive your data in a machine-readable format (data portability);
• lodge a complaint with the data protection authority in your country.
