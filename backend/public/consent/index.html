Согласие на обработку персональных данных

Дата последнего обновления: 26.08.2026

Настоящий документ описывает условия, на которых вы даёте согласие на обработку ваших персональных данных разработчику приложения «Тапа» — физическому лицу Миронов Иван (далее — «Разработчик»).

1. Данные, на обработку которых запрашивается согласие

Регистрируясь и используя Приложение через VK ID или Yandex ID, вы даёте согласие на обработку следующих данных:

  • идентификатор аккаунта VK ID / Yandex ID, адрес электронной почты и номер телефона (если провайдер их предоставляет);
  • отображаемое имя и аватар профиля;
  • данные о привычках и целях (названия, описания, настройки), в том числе созданных в рамках групповых целей;
  • статистика выполнения привычек;
  • данные о шагах за день — только если вы отдельно разрешили синхронизацию с Android Health Connect;
  • push-токен устройства для отправки напоминаний.

Мы не собираем данные аналитики использования Приложения и не создаём паролей — вход выполняется только через VK ID / Yandex ID.

2. Цели обработки

Указанные данные обрабатываются в целях:

  • предоставления функциональности Приложения (синхронизация данных между устройствами, работа с групповыми целями);
  • отправки push-уведомлений с напоминаниями о привычках;
  • синхронизации показателей физической активности с Health Connect;
  • идентификации пользователя при входе в систему;
  • связи по вопросам технической поддержки.

3. Третьи стороны

Ваши данные могут передаваться следующим сервисам для обеспечения работы Приложения:

  • VK ID (VK LLC) и/или Yandex ID (Yandex LLC) — провайдер, через который вы вошли в Приложение; передаёт нам токен доступа и базовые данные профиля;
  • Google Firebase Cloud Messaging (FCM) — доставка push-уведомлений на ваше устройство.

База данных и файлы Приложения хранятся на сервере, который контролирует Разработчик, а не на инфраструктуре стороннего облачного провайдера.

4. Срок действия согласия

Настоящее согласие действует с момента его предоставления (входа в Приложение) и до момента его отзыва или удаления учётной записи.

5. Порядок отзыва согласия

Вы вправе в любой момент отозвать настоящее согласие. Для этого необходимо:

  • удалить учётную запись через раздел настроек Приложения; или
  • направить запрос на адрес: apptapatap@gmail.com

После отзыва согласия обработка данных будет прекращена, а данные удалены в течение 30 дней.

6. Последствия отказа от предоставления согласия

Предоставление данных для входа через VK ID / Yandex ID является обязательным условием использования Приложения — без него нельзя создать учётную запись. Согласие на push-уведомления и синхронизацию с Health Connect необязательно и не влияет на возможность пользоваться остальными функциями Приложения.

7. Ваши права

В соответствии с применимым законодательством вы имеете право:

  • запросить доступ к своим персональным данным;
  • потребовать исправления неточных данных;
  • потребовать удаления данных («право на забвение»);
  • ограничить обработку данных;
  • получить данные в машиночитаемом формате (переносимость данных);
  • подать жалобу в орган по защите данных вашей страны.
