## Figma — источник правды

Все иконки, цвета, стили, компоненты и отступы берутся из Figma-файла дизайн-системы TapaDS — не придумывать самостоятельно.

**Why:** Пользователь явно установил это правило. TapaDS — единственный источник правды для визуальной части. Самостоятельные решения расходятся с дизайном.

**How to apply:**

- **Иконки** — запрашивать SVG-пути через Figma MCP (`get_design_context` или `use_figma`) из фрейма с иконками (node-id `129-193` в файле TapaDS). Или запрашивать файл с иконкой у пользователя. viewBox брать из реальных bounds пути, НЕ менять на `0 0 24 24`. `width="24" height="24"`, `fill="currentColor"`.
- **Цвета** — смотреть переменные в TapaDS, добавлять в `lib/colors.ts` если ещё нет. Использовать `useColors()` и семантические токены, не хардкодить hex.
- **Компоненты** (кнопки, инпуты, карточки) — запрашивать макет из Figma перед реализацией, если пользователь скинул node-id или ссылку.
- **Новые компоненты** — перед реализацией запрашивать из Figma макет компонента со всеми состояниями: default, pressed/active, disabled, error, loading и т.д. Не угадывать внешний вид состояний самостоятельно.
- **Отступы, радиусы, типографика** — из TapaDS, описаны в `lib/design.md`.
- Если пользователь скидывает Figma-ссылку — это задание работать по макету, не интерпретировать на глаз.

**Файлы Figma:** TapaDS (дизайн-система) — `https://www.figma.com/design/TzdQy6wcvOb4yKaz3LfJVU/TapaDS`, фрейм с иконками node-id `129-193`; Tapa App (экраны) — `yTlBE7MQqQTvxez3UP4n48`.

## Иконки: fill="currentColor" — править можно без спроса

В SVG-иконках (`assets/icons/*.svg`) `fill` на пути должен быть `fill="currentColor"`, а не захардкоженный цвет (`white`, hex и т.п.) — иначе проп `color` компонента (`<Icon color={...} />`) не действует.

**Можно** менять `fill` на `currentColor` в ассетах самостоятельно, без отдельного разрешения — это явно одобренная правка (пользователь экспортирует иконки из Figma, где fill часто остаётся `white`).

**How to apply:** При работе с иконкой, у которой `fill="white"` (или другой хардкод) на `<path>` — заменить на `fill="currentColor"`. `fill="none"` на корневом `<svg>` НЕ трогать (это правильно). Прочее содержимое SVG (viewBox, путь, размеры) без явной просьбы не менять.
