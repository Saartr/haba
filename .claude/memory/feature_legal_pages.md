Юридические тексты живут в `.legal-src/*.txt`, генератор `node .legal-src/gen.js` пишет из них
**сразу два места**: `lib/legal-content.ts` (экран «О приложении») и статические страницы в
`backend/public/`. HTML и `.ts` руками не править — только `.txt` + перезапуск генератора.

Страницы (RU на корне адреса, EN — `/en/`): `https://apptapa.ru/privacy`, `/terms`
(в коде `agreement`), `/consent`, `/delete-account`. Отдаёт их nginx из `backend/public`
(`try_files $uri $uri/index.html`), правка nginx не нужна; выкладка — коммит + `./deploy-backend.ps1`.

**Why:** Google Play при публикации (2026-09-11) требует публичную ссылку на политику
конфиденциальности без входа в приложение и отдельную веб-ссылку, где можно запросить удаление
аккаунта без приложения (раздел Data safety). Страница удаления есть только на сайте, в
приложение не попадает — там для этого кнопка «Удалить аккаунт» в профиле.

**How to apply:**
- Текст на сайте обновляется деплоем бэкенда, а в приложении — **только с новой сборкой**.
  Меняя `.txt`, помнить про оба канала, иначе сайт и приложение разойдутся.
- Страница удаления описывает поведение `DELETE /auth/me` (`backend/src/api/auth.js`) и сроки,
  сверенные с сервером: бэкапы `find -mtime +14 -delete` в `/root/backup-db.sh`, логи nginx
  `daily` + `rotate 14`. Поменялась логика удаления или ротация — поправить
  `Удаление аккаунта_ru.txt` / `delete-account_en.txt`.
- ⚠️ Не решено: в политике (п. 5) и согласии написано, что данные лежат на сервере разработчика
  «а не на инфраструктуре стороннего облачного провайдера». Фактически это арендованный VDS
  Selectel в Санкт-Петербурге ([[infra-stack]]). Опубликовано как есть — ждёт решения пользователя.
