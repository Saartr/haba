Михаил и Петр свернули проект: кончилась мотивация. Последняя работа — 2026-09-21: смена пакета
на `ru.apptapa.app` и AAB versionCode 5 в Play Console. Дальше упёрлись в закрытое тестирование
(12 тестировщиков × 14 дней) и не продолжили. Состояние Play — [[infra-google-play]].

**Решения на момент заморозки:**
- **Сервер Selectel не выключаем и не продлеваем.** Работает, пока не кончится баланс, после
  чего Selectel заблокирует и удалит его сам. Один раз это уже случилось: около 2026-10-14 сервер
  отключили за неуплату, 2026-10-23 Михаил пополнил баланс, и сервер поднялся.
- На том же сервере живёт **`kanban.apptapa.ru`** (отдельное Node-приложение на порту 1337,
  к Тапе не относится) — умрёт вместе с сервером.
- **Карточка в RuStore остаётся** как есть (versionCode 2, пакет `pro.mihmih.haba`). Когда
  сервер удалят, приложение у пользователей перестанет работать.
- В Play ничего не опубликовано: выпуск без тестировщиков никому не виден.

## Как поднять заново

Код целиком в git (`github.com/Saartr/haba`). Новый VDS → Node 22, PostgreSQL 16, nginx →
`git clone` в `/var/www/haba` → `backend.env` в `backend/.env` → создать БД и
`pg_restore -d stepbot stepbot_final_*.dump` → распаковать аватары в `backend/public/` →
nginx из архива → `certbot --nginx -d apptapa.ru -d www.apptapa.ru` → DNS на новый IP →
`pm2 start npm --name step-bot -- start` в `backend/` → cron бэкапов из архива.
Подробности деплоя — [[rules-backend-deploy]], стек — [[infra-stack]].

**Why:** без этой записи через полгода никто не вспомнит, что сервер удалён намеренно, где
лежат данные и почему приложение в RuStore не работает.

**How to apply:**
- Вернулись к проекту — сначала проверить, жив ли сервер (`curl https://apptapa.ru/health`).
  Если нет — поднимать по шагам выше, данные брать из архива (всё, что было после 2026-10-23,
  потеряно)
- **Домен `apptapa.ru` продлевается отдельно от сервера** — решено пока продлевать (2026-10-23). На нём держатся вход через Яндекс/VK
  на iOS, страницы для Play и имя пакета `ru.apptapa.app`. Потерять домен хуже, чем сервер
- Ключ подписи терять нельзя: без него не выпустить обновление ни в RuStore, ни в Play
